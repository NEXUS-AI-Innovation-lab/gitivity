================================================================================
VARIABLES D'ENVIRONNEMENT
================================================================================
Fichier          Usage
---------------------------------------------------------------------------
.env.example     Template — services sur localhost
.env.docker      Docker — hostnames = noms de conteneurs
.env.test        Tests automatisés — mock n8n

IMPORTANT : en mode Docker, utiliser .env.docker où tous les hôtes sont les
noms de conteneurs (postgres, rabbitmq, redis...). MidPoint utilise 172.17.0.1
pour accéder aux services sur l'hôte Docker.

================================================================================
LANCEMENT RAPIDE
================================================================================
# Core uniquement
docker-compose up -d

# Avec les services cibles
docker-compose --profile targets up -d

# Avec MidPoint
docker-compose --profile midpoint up -d
